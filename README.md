# Maiden Name Display (Gramps addon)

Shows a married woman as **Given Married (Maiden)** everywhere in Gramps, for example
*Ladislava Slováčková (Malotová)*.

In many genealogical traditions (Czech, Slovak and others) a married woman has to stay
recognisable by her maiden name: in parish registers and within the family many people
knew her only under it. Gramps can only display one name record, so the maiden surname
disappears once the married name is preferred. This addon composes the display from the
two names you already store.

## Rules

| Stored data | Displayed |
|---|---|
| Female, preferred **Married Name** *Ladislava Slováčková*, alternate **Birth Name** *Ladislava Malotová* | Ladislava Slováčková (Malotová) |
| Same, name format "Surname, Given" | Slováčková (Malotová), Ladislava |
| Kept both surnames: one Married Name with two surnames *Slováčková* + *Malotová* | Ladislava Slováčková Malotová (no brackets) |
| Kept both surnames typed as one text *Hábová Janečková* or *Hábová-Janečková* | unchanged, no brackets |
| Birth Name surname equals married surname | Ladislava Slováčková |
| Anyone with preferred **Also Known As** *Rudolf Vaněk* (a changed surname) and Birth Name *Rudolf Vocásek* | Rudolf Vaněk (Vocásek) |
| Spelling variants stored as alternate Also Known As names, preferred Birth Name | unchanged |
| Men with a Married Name, unmarried women, people without a Birth Name | unchanged |

Nothing is written to the database. Correct the Birth Name or the Married Name and the
display follows. Nothing is inferred either: only the explicit name types are used.

## Where it applies

The addon wraps `NameDisplay.display`, `display_formal`, `display_format` and `sorted`
(used by reports, charts, editors and most views) and the name column of the People view.
Code that formats a bare `Name` object via `display_name(name)` is not affected, because
it has no access to the person's other names.

## Install

Download or clone this repository and copy its folder (any name, e.g. `MaidenNameDisplay`)
into your Gramps user plugin directory
(`~/Library/Application Support/gramps/gramps60/plugins` on macOS,
`~/.local/share/gramps/gramps60/plugins` on Linux,
`%APPDATA%\gramps\gramps60\plugins` on Windows) and restart Gramps.
Requires Gramps 6.0.

## Tests

```
python3.13 -m pytest tests/
```

`tests/conftest.py` imports the Gramps library from the macOS app bundle with GLib stubbed;
set `GRAMPS_SITE` to use another installation.

## Status

0.2.0. Verified with unit tests, with reports generated by Gramps 6.0.8 and in the
Gramps 6.0.8 GUI on macOS (People view, person details, editor title).

The long-term goal is a core feature, e.g. a name-format keyword for the birth surname,
following gramps-project/gramps#1440.
